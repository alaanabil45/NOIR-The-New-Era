# Sourcing real photography for NØIR

I can't download or generate real photos from inside this environment
(no network access, no image-generation tool), so every file below is
still the generated placeholder. Replace them yourself with real
photography from a site that licenses images for commercial use —
Unsplash (unsplash.com/license) and Pexels (pexels.com/license) are
both free for commercial use with no attribution required.

Save each replacement with the **exact same filename**, same folder,
roughly the same aspect ratio noted below, and the site updates with
zero code changes.

Tips for a consistent look once you're sourcing:
- Stick to one lighting mood (all studio, or all outdoor overcast) so
  the scenes don't feel stitched together from different shoots.
- Desaturate slightly and keep a consistent black point if the sources
  vary — a quick Lightroom/Photoshop preset across all files fixes this
  fast.
- For the fabric macro shots specifically, a genuinely close-up texture
  photo (not a full garment shot) is what makes the FabricReveal scene
  read as "you don't know what you're looking at yet."
